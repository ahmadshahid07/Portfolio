## 🚀 Getting Started Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (v16 or higher)

### Run the Preview Server

```bash
# Clone the repository
git clone https://github.com/ahmadshahid07/Portfolio.git

# Navigate into the project directory
cd Portfolio

# Start the local server
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🌐 Deployment

This project is pre-configured with `vercel.json` for zero-configuration deployment to [Vercel](https://vercel.com/):

```bash
vercel --prod
```
